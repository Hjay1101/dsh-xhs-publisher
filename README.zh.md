# dsh-xhs-publisher

一个 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) Web GUI 的**纯客户端插件**：小红书（RED）图文发布助手。把 AI 写好的稿子粘进来——校验字数、生成封面、一键复制，直接粘贴到小红书发布。

## 为什么需要它

- 小红书笔记有明确的格式约束：**标题 ≤ 20 字、正文 ≤ 1000 字、标签 5-8 个**，手动数很烦
- 封面要 3:4 竖版（1242×1656），每次做图都要开设计工具
- 发布流程重复：起标题 → 写正文 → 做封面 → 贴标签 → 检查

## 功能

- **📝 发布内容编辑器**：标题/正文/标签输入框 + **实时字数校验**（标题 ≤20、正文 ≤1000，超限标红）
- **🎨 Canvas 封面生成器**：两套模板（深色网格 / 浅色简约），实时预览，一键导出 1242×1656 PNG——不依赖任何截图/图像工具
- **📋 发布检查清单**：标题字数 / 正文字数 / 标签数量 / 封面已导出，逐项自动判定
- **🚀 就绪动作**：一键复制（标题+正文+标签）到剪贴板、打开小红书创作平台
- **💡 无单独 LLM 配置**：文案由 DSH 现有 agent（当前会话的模型）在对话中撰写，插件只负责流程工具链

## 安装

```sh
dsh plugin --profile web add github:Hjay1101/dsh-xhs-publisher
```

在你的 profile patch 层（`$DSH_HOME/profiles/web/cordis.patch.yml`）加入插件行：

```yaml
- insert:
    - id: xhs-publisher
      name: 'dsh-xhs-publisher'
```

重启 `dsh web` 使客户端 bundle 生效，然后 设置 → 侧边栏「小红书发布助手」即可使用。

## 使用流程

1. 在对话里让 AI（当前会话的模型）按小红书规则写标题、正文、标签
2. 打开 设置 → 小红书发布助手，把稿子粘进对应输入框——字数自动校验
3. 编辑封面参数（标题/高亮词/副标题/三行用量/底部卖点），选模板，实时预览
4. 点「导出封面 PNG」下载 1242×1656 封面
5. 检查清单全绿后，「复制标题+正文+标签」，打开小红书创作平台粘贴发布
6. 链接放评论区置顶（正文别放外链）

## 工作原理

纯客户端插件：无 Host 业务（`index.js` 仅为可被 cordis 加载的空入口）、无 Typert Remote、无密钥。浏览器侧完成编辑、校验、Canvas 绘图与剪贴板，经 `settings.section` 槽位挂载。

## 已知限制

- 小红书无开放发布 API，**不能全自动发布**；插件负责"创作就绪"（内容 + 封面 + 校验 + 打包），最后一步粘贴发布由你完成
- 封面为内置模板绘制，非小红书上原样 1:1 预览；导出为高分辨率 PNG 后由平台压缩
